# BUG-009: Login takes about 5 seconds

| | |
| --- | --- |
| **System** | SauceDemo |
| **Environment** | https://www.saucedemo.com/, Chromium, Firefox, WebKit; Windows 11; home broadband |
| **Test user / data** | `performance_glitch_user` |
| **Severity** | Minor (works, but far outside the 2 s budget; users may click twice or give up) |
| **Priority** | P3 |
| **Found by** | Exploratory session 2026-11-16, confirmed by TC-SD-033 |
| **Reproducibility** | Always |
| **Status** | Open |

## Steps to reproduce

1. On the login page, enter `performance_glitch_user` / `secret_sauce`.
2. Click **Login** and time until the product list is visible.

## Expected result

Under 2 seconds, like the other users (≈ 0.1 s for `standard_user` on the same connection).

## Actual result

**≈ 5.1 s** on every attempt. During that time there is no loading indicator.

## Evidence

Measured by `scripts/capture-evidence.ts` (prints the login time) and by TC-SD-033 in `tests/saucedemo/non-functional.spec.ts`, which records the time as an annotation in the report.

## Notes

Measured as a single request on one machine, which is enough to show the difference between users. It is not a load test.
